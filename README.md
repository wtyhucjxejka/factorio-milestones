## Overview

Milestones records the exact in-game time at which your Factorio run first produces, researches, or launches specific items and technologies — creating a complete progress log. The built-in leaderboard format makes milestone times directly comparable to published speedrun times, and custom milestone lists allow tracking unique progression goals.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Milestones** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Time Tracking** | Records the exact game-time when each milestone is first achieved |
| **Research Log** | Timestamps every technology research completion in chronological order |
| **Production Firsts** | Logs first production of every intermediate and end-product item |
| **Custom Milestones** | Define custom milestone conditions and target times for personal goals |
